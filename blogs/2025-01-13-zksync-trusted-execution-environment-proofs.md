This article explains Trusted Execution Environments (TEEs), focusing on Intel's Software Guard Extensions (SGX) and their uses in enhancing blockchain security on ZKsync Era. It covers the key features of TEEs, introduces SGX, and details ZKsync TEE proofs, which include cryptographic signatures and SGX attestation reports. The article also provides instructions on how to verify these proofs using the verify-era-proof-attestation tool with Docker.
